1. Choose a row library

A row library travels with the email session, as reusableRows. The agent searches it in the words of the brief, reads what a row contains, and places the approved row instead of building a new one. A synced row is placed as it is, never edited.

Four rows saved from the Beefree builder. The agent searches them by name, category, description and tags.
